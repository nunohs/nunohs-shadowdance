# 🎶 Shadow Dance

**Shadow Dance** is a Java-based 2D rhythm game inspired by *Guitar Hero*. Players must hit the right keys in time with the music to score points and progress through increasingly challenging levels.

This project was developed as part of my 2nd year university coursework to explore game development principles and deepen my understanding of Java and object-oriented programming.

---

## 📌 Features

- 🎵 Custom music tracks
- 🎮 Multiple levels with increasing difficulty
- ✨ Rhythm-based gameplay

---

## 🧰 Technologies Used

- **Java**
- **Object-Oriented Programming (OOP)**
- **2D Game Development**
